
# Roblox Avatar Downloader 🖤💛

A simple Roblox Avatar Downloader website with a black-and-yellow design.

## Features

- Search for Roblox usernames
- Preview public Roblox avatar thumbnails
- Open avatar images
- Mobile-friendly layout
- Black-and-yellow theme

## Website

Hosted with GitHub Pages.

## Setup

1. Keep `index.html` in the root of the repository.
2. Open your repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for deployment.

## Important

GitHub Pages only hosts static websites. Direct requests to Roblox APIs may be blocked by browser security. A backend may be required to make username searching work reliably.

This is an unofficial fan-made project and is not affiliated with Roblox.
